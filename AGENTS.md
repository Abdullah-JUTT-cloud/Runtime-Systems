## Project background

Runtime Systems is a Lahore-based software engineering and technology agency serving ambitious companies worldwide. The site positions the company as a premium engineering partner focused on product engineering, AI systems, mobile applications, backend architecture, and cloud infrastructure. Its central promise is: “We don’t just build software. We engineer systems that run.”

## Product shape

- Static React + TypeScript + Vite flagship marketing site with client routing plus generated HTML entry files for reliable deep links on static hosting.
- Light-only visual system built around precise grids, runtime nodes, data paths, system labels, and a restrained signal-red accent.
- Interactive WebGL Runtime Core on capable desktops, with reduced-motion and CSS fallbacks for constrained devices.
- Complete routes for home, six work details, services and five service details, solutions, process, about, insights, careers, contact, and not-found states.
- Centralized editable content for projects, services, insights, team, navigation, social links, and site metadata.
- Frontend-only, validated multi-step project brief with an explicit non-persistent demo submission state; no fabricated client claims, metrics, testimonials, team members, or openings.
- Accessibility, responsive layouts, lazy-loaded 3D, route transitions, loading states, SEO metadata, sitemap/robots assets, and documentation are required.
- Production output remains `dist/`; no server, database, authentication, or persistent form submission is included.
